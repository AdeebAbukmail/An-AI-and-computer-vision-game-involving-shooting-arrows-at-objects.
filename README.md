# 🎮 AI & Computer Vision Hand-Controlled 2D Game

## 📌 About the Game

This is a **2D action game powered by Artificial Intelligence (AI) and Computer Vision (CV)**, where the player controls a game character using either a **keyboard** or **hand gestures detected through a camera**.

The idea behind the game is to provide a different and entertaining gaming experience by allowing players to interact with the game without relying only on traditional keyboard or touch controls.

---

## 🕹️ How to Play

The game features a 2D character that can move in four directions.

### ⌨️ Keyboard Controls

The character can be controlled using:

* **Arrow Keys** — Move left, right, forward, or backward.
* **WASD** — Move the character in the four directions.

### ✋ Hand Gesture Controls

The camera detects the player's hand movements and uses specific gestures to control attacks.

#### 👊 Closed Hand

When you **close your hand into a fist**, the character fires **one projectile**.

#### ☝️ Raised Index Finger

When you **raise your index finger**, the character fires **five projectiles in different directions**.

#### 🤲 Hands Close Together

When you **bring your hands close to each other**, the character launches a **powerful bomb attack**.

---

## 🎯 Game Objective

The main goal is to:

* Collect as many points as possible.
* Avoid collisions with enemy projectiles.
* Avoid colliding directly with enemy characters.
* Use the different attacks effectively to continue playing and achieve a higher score.

The combination of movement, shooting, bombs, and hand gestures makes the gameplay more interactive and dynamic.

---

## 🤖 Artificial Intelligence & Computer Vision

The game uses **Computer Vision** to detect and interpret the player's hand gestures through the camera.

Instead of controlling the game exclusively with a keyboard or touchscreen, the player can interact with the game using natural hand movements.

This creates a unique gaming experience where **AI and Computer Vision become part of the gameplay itself**.

---

## 💡 What Makes It Different?

Many traditional games rely on keyboards, controllers, or touchscreens.

This project explores a different approach by allowing the player to control gameplay through **AI-powered hand gesture recognition**.

The experience is designed to be fun and unusual because players are not yet accustomed to playing games through **Computer Vision and gesture-based interaction**.
